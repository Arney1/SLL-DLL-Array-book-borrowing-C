# Library Borrowing System in C

A C project that simulates a simple book borrowing system using multiple data structure implementations.

## Features

- Add and manage books
- Add and manage users/anggota
- Borrow and return books
- Queue-based waiting system
- Borrower tracking
- Multiple data structure versions:
  - Singly linked list
  - Doubly linked list
  - Array-based version

## Project Structure

- `single/` — single linked list implementation
- `double/` — double linked list implementation
- `array/` — array-based implementation

## Purpose

This project was created as a data structures assignment to compare different ways of managing the same borrowing workflow.

## Notes

This repository is educational and demonstrates data structure usage rather than production-ready design.
